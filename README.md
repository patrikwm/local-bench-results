# Local Bench: results

Live results of the Local Bench project: can open-weight AI models on one gaming PC
(RTX 4080 16 GB, 64 GB RAM) replace a paid cloud AI subscription for programming?

Page: https://patrikwm.github.io/local-bench-results/

- Coding tasks in Python, C++ and Rust, graded by hidden tests (objective, no AI judges).
- Two open-source agents, Pi and OpenCode; every task 3 times per agent.
- `data.json` holds the aggregates; it is regenerated from the benchmark harness after each run.
